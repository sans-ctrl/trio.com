# TRIØ Clothing Store

The website for TRIØ Clothing: streetwear, shoes and accessories from Leeds.

## Put it online with GitHub Pages

1. Create a new **public** repository on GitHub (for example `trio-store`).
2. Click **Add file → Upload files** and drag in everything from this folder:
   `index.html`, the `img` folder, `README.md` and `.nojekyll`.
3. Click **Commit changes**.
4. Go to **Settings → Pages**.
5. Under **Build and deployment → Source**, choose **Deploy from a branch**.
6. Pick the `main` branch and the `/ (root)` folder, then click **Save**.
7. After a minute or two your site is live at
   `https://YOUR-USERNAME.github.io/trio-store/`

## Changing things

- Products, prices and descriptions are in the list near the bottom of `index.html` (look for `const P = [`).
- Product photos are in the `img` folder. Replace a file with a sharper photo using the same name.
- Prices on the site are examples until the real ones are set.
- Checkout is not connected yet. Once the products are live on a shop (for example a Printify Pop-Up Store), link the Checkout button to it.
